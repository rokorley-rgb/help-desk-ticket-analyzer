# Help Desk Ticket Analyzer

## Project Overview

This is a beginner Python project that analyzes practice help desk tickets. The project reviews common IT support issues, organizes them by category, and counts how many tickets require escalation.

## Skills Demonstrated

- Python basics
- Lists and dictionaries
- For loops
- Conditional logic
- Help desk ticket analysis
- Escalation tracking
- Technical documentation

## Ticket Categories

The project includes practice tickets related to:

- Slow computer performance
- Wi-Fi connected but no internet
- Windows update/security warning
- Startup apps slowing boot time
- Software/application not opening

## What the Program Does

The Python script calculates:

- Total tickets reviewed
- Tickets requiring escalation
- Tickets resolved without escalation
- Ticket count by category
- Simple ticket summary

## Career Relevance

This project supports entry-level IT Support, Help Desk Technician, Application Support Specialist, and Technical Support Specialist roles by showing beginner technical documentation and Python-based ticket analysis.
